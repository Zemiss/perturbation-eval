# VCC2026 counts implementation plan

> **For agentic workers:** Execute in this session with tests and review before publication.

**Goal:** Make the default three-path evaluator compute cell-eval2's six VCC2026 metrics from original single-cell counts.

**Architecture:** Call cell-eval2 0.18.0's own preset, metric dispatcher and aggregate function. Accept H5AD inputs with matching axes and labels, preserve cells for Wilcoxon and jackknife calculations, and reject normalized, fractional, negative or nonfinite input. Keep the old four-metric protocols explicitly accessible as legacy commands.

**Tech stack:** Python >=3.11, cell-eval2==0.18.0, pdex==0.3.0 (CPU reference backend), AnnData, NumPy, SciPy, Polars.

The user chose strict counts rather than the supported lognorm adaptation on 2026-10-16. Required arguments remain `--pred-path`, `--truth-path`, `--output-dir`. Optional label/target-map flags describe the input without changing the scoring rule. Defaults preserve upstream device/backend auto selection; explicit CPU pins pdex and explicit CUDA uses gpudge. One input pair describes one context; no pooling of distinct contexts, no inferred train/test splits or shared-gene intersections. The six outputs are raw metric aggregates, not a competition total calibrated against unavailable baseline/replicate anchors.
